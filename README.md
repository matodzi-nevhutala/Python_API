# ⚡ CYBER_OS // Terminal API

A retro-futuristic Cyberpunk Command Terminal built using **Python** and **Flask**. This project provides an interactive web layout and serves RESTful API endpoints for system diagnostics, agent lists, classified logs, and dynamic command executions.

---

## 🚀 Features

* **Cyberpunk Dashboard:** A retro terminal page served directly from the root route (`/`).
* **System Status Endpoint:** Real-time JSON diagnostics reporting server node health and memory load.
* **Classified Data Records:** Dynamic URL routes to access confidential project files.
* **Interactive Command Execution:** Query parameter routing allowing users to issue custom terminal commands like `override` or `reboot`.

---

## 🛠️ Tech Stack

* **Language:** Python 3
* **Framework:** Flask
* **Frontend:** Inline HTML5 / CSS3
